> My agent asks my permission for everything, then submits while I'm still reading the question — the world's politest disobedience.

`main.py` holds the line as a literal, checks it against the
competition's gate at run time (1–200 characters, one line, no
leading or trailing whitespace, ending on a full stop), and writes
it to `/output/entry.txt`. No network, no input files.
